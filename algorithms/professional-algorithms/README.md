# Algorithms in JavaScript

## Professional Algorithms

Five JavaScript exercises focusing on algorithmic
problem-solving, number sequences, strings,
and more advanced programming logic.

### Exercises

1. **Game of 3s** — `game-of-3s.js`
2. **Magic Squares** — `magic-squares.js`
3. **Search and Replace** — `search-and-replace.js`
4. **Sum All Primes** — `sum-all-primes.js`
5. **Sum All Odd Fibonacci** — `sum-all-odd-fibonacci.js`

### Documentation

Each JavaScript file includes comments documenting the
algorithm, reasoning, and learning discoveries.
