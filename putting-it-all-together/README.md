# Putting It All Together

## Object-Oriented Programming — JavaScript ES6

A JavaScript assignment combining classes, objects, callbacks, the `this` keyword, Promises, and DOM manipulation.

### Exercises

1. **Classes** — Create a `Person` class with a constructor and an `introduce()` method.
2. **Callbacks and `this`** — Create a person instance and execute a named callback using `.call()` to set its `this` context.
3. **Promises** — Create a `wait()` function that returns a Promise resolved after a delay using `setTimeout()`.
4. **Putting It All Together** — Connect JavaScript to HTML and display the results in the browser.

### Files

- `index.html` — HTML structure and elements for displaying the results.
- `script.js` — JavaScript implementation, tests, and learning documentation.

### Documentation

The JavaScript file includes comments documenting the exercises, reasoning, and personal learning discoveries.

### Progress

All four exercises completed and tested in the browser.
