# Algorithms in JavaScript

## Basic Algorithms

Eight introductory JavaScript exercises focusing on loops,
conditions, arrays, and basic calculations.

### Exercises

1. **Print 1–135** — `print-1-to-135.js`
2. **Print Odd Numbers 1–135** — `print-odd-numbers.js`
3. **Sum of Printed Numbers** — `sum-of-printed-numbers.js`
4. **Print the Elements of an Array** — `print-array-elements.js`
5. **Find Max** — `find-max.js`
6. **Get Average** — `get-average.js`
7. **Eliminate the Negatives** — `eliminate-negatives.js`
8. **Number to String** — `number-to-string.js`

Each JavaScript file includes comments documenting the
algorithm, reasoning, and learning discoveries.
