# Algorithms in JavaScript

## Intermediate Algorithms

Five JavaScript exercises focusing on arrays, strings,
functions, and algorithmic problem-solving.

### Exercises

1. **Largest Number in Arrays** — `largest-number-in-arrays.js`
2. **Find the Longest Word in a String** — `find-longest-word.js`
3. **Title Case a Sentence** — `title-case-sentence.js`
4. **Sum All Numbers in a Range** — `sum-all-numbers-in-range.js`
5. **Fibonacci Sequence** — `fibonacci-sequence.js`

### Documentation

Each JavaScript file includes comments documenting the
algorithm, reasoning, and learning discoveries.
