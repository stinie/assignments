# Algorithms in JavaScript

## Recursion Algorithms

Five JavaScript exercises focusing on recursion,
recursive functions, base cases, and algorithmic
problem-solving.

### Exercises

1. **rFactorial vs iFactorial** — `factorial.js`
2. **Bunny Ears** — `bunny-ears.js`
3. **Power N** — `power-n.js`
4. **iFib vs rFib** — `ifib-vs-rfib.js`
5. **r Triangle** — `r-triangle.js`

### Documentation

Each JavaScript file includes comments documenting the
algorithm, reasoning, and learning discoveries.
