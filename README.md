# Assignments

Coursework for **Matrix Master #23 — Full Stack Web Development, 2026**.

This repository follows my learning journey through HTML, CSS, JavaScript, and algorithmic problem-solving. It contains individual web projects, groups of JavaScript exercises, and algorithm exercises organized into nested folders.

### Algorithms

The `algorithms` folder contains five exercise groups.

| Folder | What it covers |
| --- | --- |
| `algorithms/basic-algorithms` | 17 exercises covering loops, conditions, arrays, calculations, FizzBuzz, palindromes, and Fibonacci numbers |
| `algorithms/intermediate-algorithms` | Five exercises covering nested arrays, string processing, range sums, and Fibonacci numbers using `BigInt` |
| `algorithms/professional-algorithms` | Five exercises covering Game of 3s, magic squares, search and replace, prime sums, and odd Fibonacci sums |
| `algorithms/recursion-algorithms` | Five exercises covering base cases, recursive calculations, and comparisons with iterative approaches |
| `algorithms/sorting-algorithms` | Bubble Sort and Selection Sort, sorting copies of arrays in ascending order |

## Running the assignments

- For assignments with an `index.html`, open it in a browser or use Live Server.
- Standalone JavaScript exercises can be run individually with Node.js, for example: `node algorithms/basic-algorithms/find-max.js`.
- `function_exercises/index.html` provides browser interactions for Exercises 1, 3, and 4.
- Some pages load frameworks, fonts, or icons from CDNs and need an internet connection.

No build step is required.
