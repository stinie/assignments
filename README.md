# Assignments

Coursework for **Matrix Master #23 — Full Stack Web Development, 2026**.

Each folder is a standalone assignment — a self-contained mini-project with its own `index.html` (plus `style.css` / `script.js` where needed). To view one, open its `index.html` in a browser or run it with Live Server.

## Structure

The repository is flat: **one folder per assignment**, grouped below by topic.

### HTML fundamentals
| Folder | What it covers |
| --- | --- |
| `fix-indentation` | Cleaning up and properly indenting HTML |
| `code-validation` | Writing valid, W3C-compliant markup |
| `my-first-website` | First hand-built HTML page |

### CSS & layouts
| Folder | What it covers |
| --- | --- |
| `evil-hacker` | CSS styling exercise (The Evil Hacker) |
| `google` | Recreating the Google homepage |
| `craigslist` | Flexbox layout |
| `airbnb` | Airbnb-style page layout |
| `linkedin` | LinkedIn-style page layout |
| `twitter` | Twitter sign-in layout |

### CSS frameworks
| Folder | What it covers |
| --- | --- |
| `bootstrap` | Page built with Bootstrap |
| `materialize` | Page built with Materialize CSS |
| `my-first-framework-website` | Landing page using a CSS framework |

### JavaScript
| Folder | What it covers |
| --- | --- |
| `dom-manipulation` | Manipulating the DOM with vanilla JavaScript |
| `the-calculator` | A working calculator |
| `bring-everything-together` | Capstone combining HTML, CSS & JS |

## Tech

HTML5, CSS3, and vanilla JavaScript. No build step — everything runs straight in the browser.
