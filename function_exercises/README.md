# Function Exercises

Five JavaScript exercises from the Functions block.

## Exercises

- `exercise-1.js` — Check age
- `exercise-2.js` — Power
- `exercise-3.js` — Ask
- `exercise-4.js` — Calculator
- `exercise-5.js` — Minimum
- `index.html` — Browser-based testing for Exercises 1, 3, and 4


## Learning approach

I used AI to help me structure the exercises and keep the files clear and consistent while working through them.

I tested the code as I went and only committed an exercise once I understood what the code was doing. I kept some commented-out `console.log()` statements in the files for learning and testing.

The clean structure is also part of my learning process: I want good habits to become more natural through repetition and practice.
